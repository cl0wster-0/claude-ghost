# Claude Ghost

Нажимаешь горячую клавишу, выделяешь мышкой область экрана с вопросом, и через 1–2 секунды
ответ Claude появляется в маленьком тёмно-сером полупрозрачном окошке в правом верхнем углу.
Работает через твой вход в **Claude Code CLI** (подписка), API-ключ не нужен.

## Установка (Windows 10/11)

### Установщик (рекомендуется)

1. Скачай `ClaudeGhost-Setup.exe` со страницы **Releases** (или из артефактов последней сборки во вкладке **Actions**).
2. Запусти его. Права администратора не нужны. Можно отметить ярлык на рабочем столе и автозапуск при входе в Windows.
3. После запуска нажми `Ctrl+Shift+M`. Если Claude Code CLI не установлен, там будет кнопка
   **«Установить CLI и войти»**: она поставит CLI и откроет вход в аккаунт Claude (Pro/Max) в браузере.
   Если CLI уже есть, кнопка **«Войти»** или **«Сменить аккаунт»**.

Модель распознавания речи (~150 МБ) скачивается автоматически при первом запуске.
Настройки лежат в `%APPDATA%\ClaudeGhost\config.json`, ошибки пишутся в `%APPDATA%\ClaudeGhost\error.log`.

### Из исходников

1. **Python 3.10+** с python.org (отметь «Add python.exe to PATH»).
2. `install.bat` — поставит библиотеки.
3. `start.bat` — запуск в фоне, `start-debug.bat` — с консолью для отладки.

### Сборка exe и установщика

Сборка идёт автоматически в GitHub Actions на каждый пуш в `main`; при пуше тега `v*`
установщик прикладывается к релизу. Локально: установи Inno Setup 6 и выполни
`powershell -ExecutionPolicy Bypass -File build.ps1`, результат в `dist\ClaudeGhost-Setup.exe`.

## Управление

| Действие | Клавиши |
|---|---|
| Выделить область и спросить | `Ctrl+Shift+Space` |
| Голосовой вопрос: начать / закончить запись | `Ctrl+Shift+V` |
| Модель, effort и вход в Claude (открыть / закрыть) | `Ctrl+Shift+M` |
| Отменить выделение | `Esc` или правая кнопка мыши |
| Спрятать ответ | `Ctrl+Shift+H` или клик по окну |
| Скопировать ответ | правая кнопка мыши по окну |
| Прокрутить длинный ответ | колесо мыши |
| Закрыть программу | `Ctrl+Shift+Alt+Q` |

## Модель и effort

`Ctrl+Shift+M` открывает маленькую панель в правом верхнем углу. Выбирай мышкой или
стрелками (`←/→` — модель, `↑/↓` — effort), `Esc`/`Enter` закрывает. Выбор сохраняется сразу.

- **Модель:** Auto, Haiku (быстрее всех), Sonnet, Opus (умнее всех, медленнее).
- **Effort:** сколько модель думает перед ответом: Auto (по умолчанию модели), low … max.
  Чем выше, тем точнее на сложных вопросах, но дольше.
- **Auto** выбирает модель сам: маленький фрагмент экрана или короткий голосовой вопрос
  идут в Haiku (low), большой фрагмент, длинный вопрос или слова вроде «код», «докажи»,
  «алгоритм», «интеграл» идут в Sonnet (medium). Пороги и слова меняются в `config.json`
  (`auto_fast`, `auto_strong`, `auto_image_area`, `auto_text_chars`, `auto_hard_words`).

Над ответом серым видно, какая модель отвечала. Для выбранных настроек процессы `claude`
запускаются заранее, поэтому переключение не замедляет ответ.

## Голосовой ввод

Нажми `Ctrl+Shift+V` и говори. Пока идёт запись, в правом нижнем углу горит крошечный красный
значок микрофона. Нажми `Ctrl+Shift+V` ещё раз, и речь распознается прямо на твоём компьютере
(faster-whisper, без интернета), а текст уйдёт Claude. Твой вопрос будет серым над ответом.

При первом запуске программа один раз скачивает модель распознавания (~150 МБ для `base`),
поэтому первый голосовой вопрос может занять дольше. Запись автоматически останавливается
через 60 секунд.

## Настройки

Файл настроек: `%APPDATA%\ClaudeGhost\config.json`. Там можно поменять:

- `hotkey`, `hide_hotkey`, `quit_hotkey` — горячие клавиши (например `"alt+q"`, `"ctrl+shift+1"`);
- `model`, `effort` — то же, что в панели `Ctrl+Shift+M`; `settings_hotkey` — её клавиша;
- `system_prompt` — как Claude должен отвечать;
- `voice_hotkey` — клавиша голосового ввода; `voice_language` — язык речи (`"ru"`, `"en"` или `null` для автоопределения);
- `whisper_model` — `"base"` (быстро), `"small"` (точнее, медленнее);
- `box_width`, `box_alpha` (прозрачность 0–1), `box_bg`, `box_fg`, `font` — внешний вид;
- `auto_hide_seconds` — автоскрытие ответа через N секунд (0 = не скрывать).

После правки перезапусти программу (`Ctrl+Shift+Alt+Q`, потом снова запусти).

## Как это быстро работает

- Скриншот отправляется прямо в `claude -p` (stream-json) как картинка, без сохранения файлов.
- Процесс `claude` запускается заранее и ждёт вопроса, поэтому старт CLI (~2 с) не тратится.
- Ответ выводится по мере генерации, у Claude отключены инструменты, ответ сразу текстом.
- Окно ответа не забирает фокус и не видно в Alt+Tab.
