# Claude Ghost

Маленький помощник для Windows, который почти не мешает работать. Нажимаешь горячую клавишу,
выделяешь мышкой кусок экрана с вопросом (текст, код, формулу, ошибку, таблицу), и через пару секунд
ответ Claude появляется в маленьком тёмно-сером полупрозрачном окошке в правом верхнем углу.
Можно спросить и голосом.

Claude Ghost работает через **Claude Code CLI** и твою подписку Claude. API-ключ не нужен.

## Как это работает

```
 горячая клавиша ──► снимок экрана ──► выделяешь область ──► картинка (PNG)
                                                                  │
 голосовая клавиша ──► запись с микрофона ──► faster-whisper ──► текст
                                             (локально)           │
                                                                  ▼
                                   claude -p  (Claude Code CLI, твой вход)
                                                                  │
                                                  ответ по мере генерации
                                                                  ▼
                                      маленькое окно в правом верхнем углу
```

1. Программа живёт в фоне без окна и слушает горячие клавиши.
2. По `Ctrl+Shift+Space` она делает снимок всех мониторов и показывает его затемнённым.
   Ты выделяешь мышкой нужную область, и она вырезается в картинку.
3. Картинка (или текст голосового вопроса) уходит в `claude -p` в формате stream-json
   прямо через stdin, без временных файлов.
4. Ответ выводится в окошко по мере того, как Claude его пишет.

**Почему быстро:**

- Процессы `claude` запускаются **заранее** и ждут вопроса, поэтому старт CLI (~2 с) не тратится.
  Первые слова ответа обычно появляются примерно через секунду.
- У Claude отключены инструменты (поиск, файлы и т. п.), он отвечает сразу текстом.
- Системная подсказка просит отвечать коротко: сначала ответ, потом 1–2 строки пояснения.
- В режиме Auto простые вопросы идут в самую быструю модель.

**Почему незаметно:**

- Окно ответа маленькое, полупрозрачное, без рамки и заголовка.
- Оно не забирает фокус у программы, в которой ты работаешь, и не появляется в Alt+Tab и на панели задач.
- Пока идёт запись голоса, в правом нижнем углу горит только крошечный значок микрофона.

## Установка

Нужна Windows 10 или 11 (64-bit) и подписка Claude (Pro или Max).

1. Скачай `ClaudeGhost-Setup.exe` со страницы **Releases**
   (или из артефактов последней сборки во вкладке **Actions**).
2. Запусти установщик. Права администратора не нужны, программа ставится только для твоего пользователя.
   На шаге «Дополнительные задачи» можно отметить:
   - ярлык на рабочем столе;
   - запуск при входе в Windows.
3. В конце установщик предложит сразу запустить Claude Ghost.

Программа ставится в `%LOCALAPPDATA%\Programs\Claude Ghost`, её файл называется `CG.exe`.
Ярлыки, меню «Пуск» и список установленных приложений показывают «Claude Ghost» со значком-призраком.
Сам файл называется `CG.exe` и собран без встроенной иконки, поэтому в диспетчере задач процесс виден
как `CG.exe` с обычным значком программы.

При первом запуске программа один раз скачивает модель распознавания речи (~150 МБ),
поэтому первый голосовой вопрос может занять дольше. Скриншоты работают сразу.

Удаление: «Параметры → Приложения → Claude Ghost → Удалить».
Настройки в `%APPDATA%\ClaudeGhost` при этом остаются, их можно удалить вручную.

## Вход в Claude

Нажми `Ctrl+Shift+M`. Внизу панели есть блок аккаунта со статусом и кнопкой:

| Статус | Кнопка | Что произойдёт |
|---|---|---|
| Claude CLI не установлен | **Установить CLI и войти** | Откроется окно PowerShell: оно установит Claude Code CLI с claude.ai, затем откроет вход в браузере |
| CLI установлен, вход не выполнен | **Войти** | Откроется окно с `claude auth login`, вход в браузере |
| Вход в Claude выполнен ✓ | **Сменить аккаунт** | Выход и новый вход |

После того как окно входа закроется, статус обновится сам, и программа перезапустит свои
процессы `claude` уже с новым входом. Если CLI уже был установлен и ты в него входил раньше,
ничего делать не нужно.

## Как пользоваться

### Вопрос со скриншота

1. Нажми `Ctrl+Shift+Space`. Экран слегка потемнеет, курсор станет крестиком.
2. Выдели мышкой область с вопросом. Можно захватить несколько мониторов.
3. Отпусти кнопку. В правом верхнем углу появится окошко: сверху серым видно, какая модель отвечает,
   ниже идёт ответ.

Передумал: `Esc` или правая кнопка мыши.

### Голосовой вопрос

1. Нажми `Ctrl+Shift+V` и говори. В правом нижнем углу загорится крошечный красный значок микрофона.
2. Нажми `Ctrl+Shift+V` ещё раз. Речь распознается прямо на компьютере, и текст уйдёт Claude.
3. В окошке будет твой вопрос серым и ответ под ним.

Запись сама останавливается через 60 секунд. Язык речи по умолчанию русский (меняется в настройках).

### Окно ответа

- **Клик левой кнопкой** прячет окно, `Ctrl+Shift+H` тоже.
- **Правая кнопка** копирует ответ в буфер обмена (без markdown-разметки).
- **Колесо мыши** прокручивает длинный ответ.
- Новый вопрос сразу заменяет старый ответ. Если Claude ещё отвечал, тот ответ отменяется.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Выделить область экрана и спросить | `Ctrl+Shift+Space` |
| Голосовой вопрос: начать / закончить запись | `Ctrl+Shift+V` |
| Панель модели, effort и входа: открыть / закрыть | `Ctrl+Shift+M` |
| Отменить выделение | `Esc` или правая кнопка мыши |
| Спрятать ответ | `Ctrl+Shift+H` или клик по окну |
| Скопировать ответ | правая кнопка мыши по окну |
| Закрыть программу | `Ctrl+Shift+Alt+Q` |

Все клавиши меняются в `config.json`.

## Модель и effort, режим Auto

`Ctrl+Shift+M` открывает маленькую панель в правом верхнем углу.
Выбирай мышкой или клавишами: `←/→` меняет модель, `Tab` / `Shift+Tab` меняет версию,
`↑/↓` меняет effort. `Esc` или `Enter` закрывает.
Выбор сохраняется сразу.

**Модели:**

| Модель | Когда выбирать |
|---|---|
| **Auto** | По умолчанию. Программа сама выбирает модель для каждого вопроса (см. ниже) |
| **Haiku** | Самая быстрая. Короткие фактические вопросы, перевод, простые расчёты |
| **Sonnet** | Баланс скорости и качества. Код, объяснения, задачи в несколько шагов |
| **Opus** | Самая умная и самая медленная. Сложные рассуждения |
| **Fable** | Отдельное семейство моделей Claude, можно попробовать на своих задачах |

**Версия модели.** Для Haiku, Sonnet, Opus и Fable под строкой моделей появляется строка версий:

| Семейство | Версии |
|---|---|
| Opus | новейшая, 5.5, 5, 4.8, 4.7, 4.6, 4.5 |
| Sonnet | новейшая, 5.5, 5, 4.6, 4.5 |
| Haiku | новейшая, 5.5, 4.5 |
| Fable | новейшая, 5.2, 5 |

«Новейшая» означает алиас CLI (`opus`, `sonnet`, …), то есть самую свежую версию, доступную твоему аккаунту.
Версии в списке проверены на Claude Code CLI 2.1. Если твой CLI какую-то версию не примет,
программа покажет понятную ошибку и пометит версию знаком ✕. Если выбрать её снова, будет ещё одна попытка.
Над ответом серым видно точную версию, например «Opus 4.7 · high».

**Effort** задаёт, сколько модель думает перед ответом: `Auto` (по умолчанию для модели),
`low`, `medium`, `high`, `xhigh`, `max`. Чем выше, тем точнее на сложных вопросах, но дольше ждать.

**Как работает Auto.** Перед отправкой программа быстро, без лишних запросов, оценивает сложность вопроса:

- **простой** → Haiku, effort `low`:
  небольшой фрагмент экрана или короткий голосовой вопрос;
- **сложный** → Sonnet, effort `medium`:
  большой фрагмент экрана (больше ~300 000 пикселей, например 600×500),
  голосовой вопрос длиннее 160 символов или со словами вроде «код», «алгоритм», «докажи»,
  «выведи», «интеграл», «матрица», «почему».

Если в панели выбран конкретный effort (не Auto), он применяется к обеим моделям Auto.
Пороги, слова и сами пары «модель + effort» меняются в `config.json`.

Для выбранных настроек нужные процессы `claude` запускаются заранее (в режиме Auto сразу два),
поэтому переключение модели не замедляет ответ.

## Настройки (config.json)

Файл: `%APPDATA%\ClaudeGhost\config.json`. Он создаётся при первом запуске со всеми значениями
по умолчанию. После правки перезапусти программу (`Ctrl+Shift+Alt+Q`, затем снова запусти).

**Горячие клавиши**

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `hotkey` | `ctrl+shift+space` | Выделить область и спросить |
| `voice_hotkey` | `ctrl+shift+v` | Голосовой ввод |
| `settings_hotkey` | `ctrl+shift+m` | Панель модели и входа |
| `hide_hotkey` | `ctrl+shift+h` | Спрятать ответ |
| `quit_hotkey` | `ctrl+shift+alt+q` | Закрыть программу |

Формат как у библиотеки `keyboard`: `"alt+q"`, `"ctrl+shift+1"`, `"f9"`.

**Модель и ответы**

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `model` | `auto` | `auto`, `haiku`, `sonnet`, `opus`, `fable` |
| `versions` | `{}` | Версия для каждого семейства, например `{"opus": "claude-opus-4-7"}`; нет записи значит новейшая |
| `effort` | `auto` | `auto`, `low`, `medium`, `high`, `xhigh`, `max` |
| `system_prompt` | короткие ответы | Инструкция для Claude: стиль, длина, язык ответа |
| `auto_fast` | `["haiku", "low"]` | Модель и effort для простых вопросов в Auto |
| `auto_strong` | `["sonnet", "medium"]` | Модель и effort для сложных вопросов в Auto |
| `auto_image_area` | `300000` | Площадь фрагмента в пикселях, с которой он считается сложным |
| `auto_text_chars` | `160` | Длина голосового вопроса, с которой он считается сложным |
| `auto_hard_words` | список | Слова (или их начала), при которых вопрос считается сложным |
| `prewarm` | `true` | Держать процессы `claude` запущенными заранее |
| `max_image_side` | `1568` | Большие фрагменты уменьшаются до этого размера по длинной стороне |

**Голос**

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `voice_language` | `ru` | Язык речи: `ru`, `en`, … или `null` для автоопределения |
| `whisper_model` | `base` | `tiny`, `base`, `small`, `medium`: чем больше, тем точнее и медленнее |
| `voice_max_seconds` | `60` | Максимальная длина записи |
| `mic_icon_color` | `#e05555` | Цвет значка микрофона |

**Внешний вид окна ответа**

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `box_width` | `300` | Ширина в пикселях |
| `box_max_height` | `300` | Максимальная высота, дальше прокрутка |
| `box_margin` | `14` | Отступ от края экрана |
| `box_alpha` | `0.85` | Непрозрачность от 0 до 1 |
| `box_bg`, `box_fg` | `#2b2b2b`, `#e8e8e8` | Цвет фона и текста |
| `font` | `["Segoe UI", 9]` | Шрифт и размер |
| `auto_hide_seconds` | `0` | Спрятать ответ через N секунд, 0 значит не прятать |

**Прочее**

| Ключ | По умолчанию | Что делает |
|---|---|---|
| `check_updates` | `true` | Проверять новую версию на GitHub при запуске |

## Какие данные куда уходят

- **Скриншот выделенной области** и **текст голосового вопроса** отправляются в Claude
  через твой Claude Code CLI, так же как обычный запрос в Claude Code.
  Весь остальной экран никуда не уходит.
- **Голос** распознаётся локально моделью faster-whisper. Аудио не покидает компьютер и не сохраняется.
- Программа не хранит историю вопросов и ответов. Сессии `claude` запускаются с
  `--no-session-persistence`.
- Локально лежат только `config.json` и `error.log` в `%APPDATA%\ClaudeGhost`.

## Обновления

**Для пользователей.** Установленная через установщик программа сама проверяет обновления:
примерно через 8 секунд после запуска она смотрит последний релиз на странице **Releases** этого репозитория.
Если там версия новее, в правом верхнем углу появится сообщение:

> Доступна новая версия Claude Ghost X.Y.Z. Кликните сюда, чтобы обновить.

Клик скачивает новый установщик и тихо ставит его поверх старой версии, после чего программа перезапускается.
Настройки, вход в Claude, ярлыки и автозапуск сохраняются. `Ctrl+Shift+H` откладывает обновление
до следующего запуска. Отключить проверку: `"check_updates": false` в `config.json`.

Проверка работает, только если репозиторий **публичный**: у приватного репозитория страница релизов
недоступна без входа в GitHub. При запуске из исходников проверка не выполняется.

**Для разработчика: как выпустить новую версию.**

1. Запушь изменения в `main`.
2. Создай релиз на GitHub: **Releases → Draft a new release**, тег вида `v1.1.0`
   (номер должен быть больше предыдущего), заголовок и описание изменений → **Publish release**.
3. Публикация релиза запускает GitHub Actions: он соберёт exe с этим номером версии и прикрепит `ClaudeGhost-Setup.exe` к релизу
   (несколько минут). Пока файла в релизе нет, программы его не видят и ничего не предлагают.

Номер версии берётся из тега: `v1.1.0` → `1.1.0` в программе и в установщике.
К релизу прикладывается сам `ClaudeGhost-Setup.exe`, без zip: его можно скачать и запустить сразу,
и именно этот файл скачивает автообновление.

## Если что-то не работает

| Проблема | Что сделать |
|---|---|
| «Claude CLI не найден» | `Ctrl+Shift+M` → **Установить CLI и войти** |
| «Нужно войти» | `Ctrl+Shift+M` → **Войти** |
| Горячая клавиша не срабатывает | Её может перехватывать другая программа: поменяй клавишу в `config.json`. В окнах, запущенных от администратора, клавиши работают, только если Claude Ghost тоже запущен от администратора |
| Выделение смещено на экране с масштабом 125–150 % | Сообщи об ошибке, приложив `error.log` и масштаб экрана |
| «Микрофон недоступен» | «Параметры → Конфиденциальность → Микрофон»: разреши доступ классическим приложениям |
| Первый голосовой вопрос долго думает | Скачивается модель речи, это один раз |
| Ответ пустой или ошибка | Посмотри `%APPDATA%\ClaudeGhost\error.log` |

## Запуск из исходников и сборка

### Запуск из исходников

1. **Python 3.10+** с python.org (отметь «Add python.exe to PATH»).
2. Claude Code CLI: `irm https://claude.ai/install.ps1 | iex`, затем `claude auth login`
   (или войди позже через `Ctrl+Shift+M`).
3. `install.bat` ставит библиотеки из `requirements.txt`.
4. `start.bat` запускает в фоне, `start-debug.bat` запускает с консолью для отладки.

### Сборка exe и установщика

Сборка идёт автоматически в **GitHub Actions** (`.github/workflows/build.yml`) на каждый пуш в `main`.
Установщик появляется в артефактах сборки, а при пуше тега `v*` прикладывается к релизу.

Локально нужен Inno Setup 6:

```powershell
powershell -ExecutionPolicy Bypass -File build.ps1
```

Результат: `dist\CG\CG.exe` и установщик `dist\ClaudeGhost-Setup.exe`.
`build.ps1` также запускает `CG.exe --selftest`, чтобы проверить, что все зависимости попали в сборку.

### Структура проекта

| Файл | Что это |
|---|---|
| `ghost.py` | Всё приложение: горячие клавиши, выделение, окна, голос, запуск `claude` |
| `requirements.txt` | Библиотеки Python |
| `build.ps1` | Сборка exe (PyInstaller) и установщика (Inno Setup) |
| `installer/ClaudeGhost.iss` | Сценарий установщика: ярлыки, автозапуск, удаление |
| `assets/icon.ico` | Иконка |
| `install.bat`, `start.bat`, `start-debug.bat` | Запуск из исходников |
